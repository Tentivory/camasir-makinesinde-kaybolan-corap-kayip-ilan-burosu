# T.C. Çamaşır Makinesinde Kaybolan Çorap Kayıp İlan Bürosu

Bu depo bir şaka değildir. Çoraplar kaybolur. Devlet bunu kayda geçmek zorundadır.

## Amaç

Çamaşır makinesine **çift** giren çorabın **tek** çıkmasını ulusal güvenlik meselesi saymak, kayıp ilanı düzenlemek ve evdeki diğer çoraba taziye metni üretmektir.

Yazılım **gerçekten çalışır**. Çorap **gerçekten dönmez**. İkisi de doğrudur.

## Kurulum

```bash
python3 corap_burosu.py --renk lacivert --ayak sol --marka "Pazartesi Çorabı"
```

Çıktı resmi tutanaktır. Çerçeveletmeyiniz. Makinenin üstüne bantlayınız.

## Yasal dayanak

1. Çamaşır Kanunu (hayalî, ama kararlı)
2. Tek Çorap Yas Tutma Yönetmeliği
3. Tambur İçi Karanlık Bölge Genelgesi

## Sık sorulan sorular

**Çorap bulunur mu?**  
Hayır. Bu ürünün vaadi budur.

**Neden Türkçe?**  
Çünkü kaybolan çorap da Türkçe kaybolur.

**Bu siyasi midir?**  
Hayır. Sadece çamaşırdır. Siyaset çamaşır makinesinin içine girmez.
